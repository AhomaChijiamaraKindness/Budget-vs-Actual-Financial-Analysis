# Budget vs Actual Financial Analysis Dashboard
## Project Overview
This project analyses budgeted expenditure against actual spending to evaluate financial performance and identify areas of overspending. An interactive dashboard was developed to compare financial performance across departments, expense categories, and regions.

## Business Problem
Organisations need to monitor actual expenditure against approved budgets to control costs, identify unfavourable variances, and make informed financial decisions.

This project addresses that need by summarising budget and actual spending and presenting the results through key performance indicators (KPIs) and visual dashboards.

## Project Objectives
- Compare total budget with actual expenditure.
- Calculate budget variances and variance percentages.
- Analyse spending across departments, categories, and regions.
- Highlight potential overspending and support better budget monitoring.

## Tools Used
- **Google Sheets:** Data analysis, calculations, and dashboard development.
- **GitHub:** Project documentation and portfolio presentation.

## Key Performance Indicators (KPIs)

| Metric | Result |
|---|---:|
| Total Budget | ₦795,434,571 |
| Total Actual Spend | ₦890,255,044 |
| Budget Variance | ₦94,820,473 |
| Variance Percentage | 11.92% overspend |

## Key Findings
- Actual expenditure exceeded the total budget by **₦94,820,473**.
- Actual spending was approximately **11.92% above budget**.
- Departmental, category, and regional comparisons provide a basis for identifying areas with significant budget overruns.
- Further investigation is required to understand the causes of individual variances.

## Recommendations
- Investigate departments and expense categories with the largest unfavourable variances.
- Review the reasons for overspending, including price increases, higher activity levels, and initial budgeting assumptions.
- Monitor actual expenditure against budget regularly to identify overruns early.
- Strengthen expenditure approval processes and require explanations for significant variances.
- Use historical spending patterns to improve future budgeting and financial planning.

## Dashboard Analysis
The dashboard contains four visualisations:

1. **Budget vs Actual by Department** — compares planned and actual expenditure across departments.
2. **Budget Variance by Department** — highlights differences between actual spending and budget.
3. **Budget vs Actual by Category** — compares spending across expense categories.
4. **Budget vs Actual by Region** — examines expenditure across regions.
